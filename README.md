# Aval

A P2P marketplace where two AI agents negotiate in a sealed vault, real money moves through Capital One Nessie escrow, and a voice avatar named Ava hosts the deal.

**Agents negotiate. The vault keeps secrets. Humans move money.**

## Folder ownership

| Folder | Owner | Purpose |
|---|---|---|
| web/ | Mateo | React frontend |
| spacetimedb/ | Backend | SpacetimeDB module |
| agent/ | Backend | Python LiveKit agent (Ava) |
| worker/ | Backend | Node worker that calls Nessie |
| shared/ | Shared | TypeScript types |
| docs/ | Shared | Demo script, sponsor map, data contract |
